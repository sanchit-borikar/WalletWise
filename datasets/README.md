# datasets

Open data from CardAdvisor (https://cardadvisor.in/data), downloaded 2026-10-19.

License: CC BY 4.0. Attribution required: "Data: CardAdvisor (cardadvisor.in/data), CC BY 4.0" with a link to https://cardadvisor.in/data.
Cite the `asOf` date inside each file. These are live snapshots; for a stable citation use a frozen release (https://cardadvisor.in/data/versions).

| File | Contents |
|---|---|
| cards.csv / cards.json | 280 cards: fees, forex, eligibility. The JSON adds per-category reward rows (rate, monthly cap, paisa per point, merchants) and perks |
| valuations.csv / .json | Typical paisa-per-point by card and programme |
| transfers.csv / .json | Points transfer graph (bank points to airline/hotel programmes, ratios, caps, speed) |
| lounges.csv / .json | Lounge entitlements per card |
| changes.csv / .json | Change history (devaluations, benefit changes) |
| devaluation-index.json | Frozen Sept 2026 most-devalued cards |
